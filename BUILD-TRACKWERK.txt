TrackWerk 1.1.0 - corresponding source and build notes

source/ contains the common Android and Linux application tree. No Android overlay is required
for 1.1. Earlier 1.0 publishing helpers remain in the historical tag and must not be applied to 1.1. SOURCE-SNAPSHOT.json records the export policy and file inventory.

Android
  JDK 21, Gradle 8.14.3, Android SDK 36, NDK 28.2.13676358, CMake 3.22.1.
  From source/: ./gradlew :app:assembleDebug
  A locally signed release is built with :app:assembleRelease and your own signing configuration.
  The public update APK uses com.kidbunka.trackwerk, versionName 1.1.0, versionCode 101004.
  The private release key is not included. A differently signed APK cannot update that installation.

Host shell and checks
  cmake -S source/shell -B build/host -DCMAKE_BUILD_TYPE=Release -DPT_STUDIO_CHECK=ON
  cmake --build build/host -j4
  SDL2 development files are required. The vendored source can be selected with
  -DFETCHCONTENT_SOURCE_DIR_SDL2=/absolute/path/to/source/native/vendor/SDL2
  Execute build/host/pockettracker-sdl. The pt* checks are in build/host/native/.
  The release approval run built the SDL shell and passed all 83 host checks.

Linux handheld profiles
  Use the same CMake shell target with a Zig 0.14.1 cross-toolchain and an SDL2Config.cmake
  pointing to the SDK headers and exact target SDL shared library. Set CMAKE_SKIP_RPATH=ON.
  Brick: aarch64-linux-gnu.2.31, cortex_a53, TrimUI SDL 2.26.1, PT_HANDHELD=ON.
  RGB20S AmberELEC: aarch64-linux-gnu.2.31, cortex_a35, TrimUI SDL headers, PT_HANDHELD=ON.
  Miyoo Mini: arm-linux-gnueabihf.2.28, cortex_a7, matching mmiyoo SDL,
    PT_HANDHELD=OFF, PT_MIYOO_OFFLINE=ON, PT_MIYOO_PLUS_ARCHIVE=OFF.
  Miyoo Mini Plus: same ARMv7 target, matching online mmiyoo SDL,
    PT_HANDHELD=OFF, PT_MIYOO_OFFLINE=OFF, PT_MIYOO_PLUS_ARCHIVE=ON.
  Exact mmiyoo SDL source: SDL2-mmiyoo-f6319cf9-source.tar.gz, unchanged from the 1.0 release.
  The SDK used for linking is distinct from a device's bundled runtime dependencies.

Update packages retain the established launcher and user-data directories. Follow START-HERE.
Do not overwrite a music card with a full system image to update an application.
