# TrackWerk 1.1

An open-source tracker and sample studio for Android and Linux handhelds, by Kid Bunka and contributors. Built on PocketTracker by conanizer and contributors.

## New in 1.1

- Forty complete interface scenes in ten collections, including DAYLIGHT and HARDWARE. Four arrangements of the editing workspace keep the same button workflow.
- Fifty-four palettes, sixteen optional typefaces, subtle cursor and value motion, page transitions, and a Motion switch.
- Harmony: playable chord slots and forty-eight progression templates for loaded samples, SoundFonts and external MIDI.
- Expanded synthesis including SID CHIP, DCO POLY, FM SYSEX voice banks, and spectral models. Factory presets cover instruments, granular patches, effects and mastering.
- Sample-editor improvements across rate changes, Undo, preview, memory limits, saving and WAV publication.
- Archive and radio discovery in connected profiles. YouTube is optional, disabled by default and enabled only after explicit consent.

## Make a track

Write a phrase, arrange chains and build a song across eight tracks. Load audio, slice a loop, generate a Drumlab rhythm, and perform momentary Punch effects. Internal resampling turns a performance into a reusable sample. Mix with effects and render a song or stems.

Use SELECT for contextual help. The illustrated English guide and walkthrough accompany the release.

## Devices and updates

TrimUI Brick uses KNULLI; Miyoo Mini and Mini Plus use OnionOS; RGB20S uses the AmberELEC profile; Android is supplied as a signed APK. The Mini profile is offline. Online sources require networking supported by the device.

Keep your existing data folder when updating. The Android package remains com.kidbunka.trackwerk with the existing release signer; versionCode 101003 updates over 1.0 and earlier dev.2 packages. Back up your own music before any device update.
